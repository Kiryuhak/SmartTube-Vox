## 📺 О проекте SmartTube VOX

**SmartTube VOX** — это открытый форк телевизионного плеера [SmartTube](https://github.com/yuliskov/SmartTube), расширенный технологиями нейросетевого закадрового перевода Яндекса, встроенным автономным менеджером загрузок, автоматической подстройкой аудио- и видеокодеков под возможности чипсета и инструментами безопасной диагностики совместимости.

Приложение собирается в независимый пакет (`io.github.kiryuhak.smarttubevot.stable`) с собственным каналом обновлений и настройками, что позволяет использовать его параллельно с оригинальным SmartTube. Проект развивается сообществом независимо и не является официальным продуктом SmartTube, Яндекса или Google.

## 🚀 Возможности поколения VOX 7

Поколение **SmartTube VOX 7** сосредоточено на стабильности воспроизведения, честной совместимости форматов и удобстве управления с пульта:

- **Единая архитектурная основа**: Общая спецификация возможностей устройств (`vox-device-profile-v1`) и фундамент для поддержки Android TV / Google TV и Samsung Tizen TV.
- **Автоматическая настройка (Auto Tuning)**: Определение аппаратных характеристик (объём RAM, ядра CPU, параметры дисплея, декодеры `MediaCodec`) с рекомендательным диалогом оптимального профиля.
- **Оценка рисков несовместимости**: Предупреждающий диалог при ручной попытке выбора неподдерживаемых экраном или процессором форматов с возможностью быстрого возврата к безопасным настройкам.
- **Интеллектуальный выбор кодеков**: Автоматический подбор видео (AV1, VP9, AVC) и аудио (EAC3, AC3, Opus, AAC) под процессор и подключенную акустику.
- **Режимы совместимости**: Автоматический, режим максимального качества, режим максимальной совместимости для старых ТВ-приставок и пользовательский режим.
- **Безопасная диагностика и журнал ошибок**: Структурированное логирование (`vox-diagnostic-report-v2`) в кольцевой буфер (до 500 записей / 7 дней) со строгой санитизацией персональных данных, просмотром отчёта на экране и отправкой разработчикам только по прямому действию пользователя.
- **Менеджер загрузок и библиотека «Скачанные видео»**: Постоянный доступ к скачанным видео в боковом меню, офлайн-воспроизведение сохранённых роликов и индикация свободного места.
- **Обычная и переведённая загрузка**: Поддержка сохранения как исходного видео, так и видео со встроенной дорожкой закадрового перевода через нативный мультиплексор.
- **Индикаторы качества и длительности**: Компактные капсульные бейджи (`4K · 2160p`, `2K · 1440p`, `FHD · 1080p`, `HD · 720p`, `SD · 480p`) в едином стиле без ложных завышений разрешения.
- **Плавный бегущий текст в меню**: Native Marquee для длинных заголовков бокового меню при активном фокусе с задержкой старта и возвратом к началу при смене позиции.
- **Архитектурный задел для Live-перевода**: Реализован конвейер динамической задержки (Dynamic Delay Buffer) и синхронизации чанков, честно учитывающий текущий статус бэкенда (`VOD_ONLY`).
- **Надёжность перевода**: Автоматическое определение языка речи, русскоязычные подсказки при ошибках и долговременное сохранение авторизации Яндекс ID.

## 📱 Поддерживаемые платформы

| Платформа | Статус | Подтверждение | Примечание |
|---|---|---|---|
| **Android TV / Google TV** | Поддерживается | **Runtime PASS** (Android 14 / API 34 на физическом TCL Smart TV Pro, armeabi-v7a; эмулятор x86) | Основная рабочая платформа. ExoPlayer / Jetpack Media3, Leanback UI, аппаратное ускорение MediaCodec. Для API 28–33 проверена статическая совместимость. |
| **Samsung Tizen TV** | Preview / Experimental | **Build PASS** (пакет `SmartTube-VOX-7.0.0.wgt`, 9 unit-тестов) | Чистая W3C/Tizen Web Application основа, интеграция с Samsung Product API (`webapis.avplay`) и fallback на HTML5/MSE. Физическое тестирование на реальных ТВ Samsung не проводилось. |

### Android TV / Google TV
- **Основной плеер**: Оптимизированный медиастек ExoPlayer / Jetpack Media3 с адаптивной буферизацией и навигацией пультом (D-Pad). Сторонние плееры (mpv/vlc) не используются.
- **Диапазон версий**: Целевой диапазон совместимости — Android 9–14 (API 28–34). Практическое runtime-тестирование проведено на Android TV 14 / API 34; для версий API 28–33 проведён статический аудит совместимости кода.
- **Аппаратное сканирование**: Опрос возможностей через `MediaCodecList` и `AudioTrack` без задержек в UI.
- **Безопасный откат (Fallback)**: При аппаратных сбоях декодирования плеер автоматически переключается на базовые потоки (AVC/AAC).
- **Селективный прокси**: Изолированная маршрутизация запросов к сервису перевода при сохранении прямого скоростного соединения с серверами видео.

### Samsung Tizen TV — Preview / Experimental
- **Разные платформенные пакеты**: Tizen не поддерживает запуск файлов APK. Для Android формируется APK, а для Tizen — пакет W3C Widget (WGT). Это одна продуктовая линейка SmartTube VOX с общей архитектурой возможностей, но отдельными пакетами под каждую операционную систему.
- **Текущий статус**: Сборка WGT-артефакта подтверждена (`SmartTube-VOX-7.0.0.wgt`), модульные тесты платформы пройдены. В текущем тестовом окружении Tizen Studio и Tizen Emulator отсутствуют; физическое тестирование на ТВ Samsung не выполнялось.
- **Формулировка**: Версия для Tizen документируется строго как **Preview / Experimental** (для разработчиков и исследовательских целей).

## 📥 Скачивание видео

SmartTube VOX включает встроенный конвейер загрузки и управления медиафайлами:

- **Режимы скачивания**:
  - **Обычная загрузка**: Сохранение видеопотока и оригинальной аудиодорожки;
  - **Загрузка с переводом**: Сквозная сборка видео с наложенной дорожкой перевода Яндекса, проверенная на реальном ТВ.
- **Выбор качества**: Пользователь выбирает желаемое разрешение перед стартом; на карточках отображаются как запрошенное, так и фактически полученное качество.
- **Защита от сбоев**:
  - Автоматический откат (Fallback) при недоступности выбранного потока;
  - Повторное получение свежих ссылок на потоки (URL re-resolve) при длительных загрузках;
  - Восстановление и продолжение загрузки (Resume) после обрывов связи или перезапуска приложения.
- **Локальная библиотека «Скачанные видео»**: Постоянный раздел в боковом меню и настройках для быстрого открытия сохранённых видеороликов, навигации, перемотки и удаления.
- **Очистка временных файлов**: Временные сегменты и буферы автоматически удаляются после завершения сборки файла или при отмене задачи.
- **Полная автономность**: Загрузка и сборка выполняются нативно без использования внешних рантаймов FFmpeg, yt-dlp или Python.

## 🎙 Закадровый перевод VOX

- **Нейросетевой перевод**: Поддержка стандартного закадрового перевода и режима **«Живой голос»** Яндекса.
- **Синхронизация со скоростью воспроизведения**: Перевод корректно работает на скоростях `1.0x`, `1.25x`, `1.5x`, `1.75x`, `2.0x`.
- **Автоопределение языка**: Язык оригинала определяется сервисом автоматически без ручного переключения.
- **Сохранение авторизации**: Привязка Яндекс ID через `ya.ru/device` сохраняется между перезапусками приложения.
- **Статус перевода прямых трансляций (Live Translation)**:
  - Публичный API Яндекс VOT в настоящее время работает исключительно в режиме **`VOD_ONLY`** (видео по запросу с фиксированной длительностью).
  - Клиентская архитектура SmartTube VOX (динамический буфер задержки, контроллер синхронизации чанков и модуль проверки применимости) подготовлена для будущего подключения живого перевода.
  - Из-за ограничений внешнего бэкенда перевод бесконечных прямых эфиров в настоящее время недоступен; при попытке его включения плеер выдаёт понятное русскоязычное уведомление без аварийного завершения.

## 🏷 Индикаторы качества и длительности

На карточках видео в разделах «Главная», «Подписки» и «Поиск» отображаются аккуратные капсульные бейджи:
- `4K · 2160p` (или `4K`);
- `2K · 1440p` (или `2K`);
- `FHD · 1080p` (или `FHD`);
- `HD · 720p` (или `HD`);
- `SD · 480p` / `SD · 360p` (или `SD`).

В правом нижнем углу карточки выводится длительность ролика. В библиотеке скачанных видео отображается фактическое разрешение сохранённого файла. Приложение не подставляет выдуманные значения разрешения и отображает только достоверно подтверждённые потоки.

## ⚙️ Совместимость кодеков и автонастройка (Auto Tuning)

В разделе **Настройки → Совместимость устройства** доступны:

- **Автоматическая настройка**: Сканирует аппаратные сигналы телевизора (объём RAM, количество ядер процессора, разрешение экрана и аппаратные декодеры `MediaCodec`) и предлагает оптимальный режим воспроизведения.
- **Режимы совместимости**:
  1. **Автоматически (рекомендуется)**: Оптимальный баланс между качеством и аппаратными возможностями;
  2. **Максимальное качество**: Приоритет максимального разрешения и объёмного звука среди подтверждённых кодеков;
  3. **Максимальная совместимость**: Принудительный выбор AVC и AAC для исключения подтормаживаний на слабых ТВ-боксах;
  4. **Пользовательский**: Ручной выбор кодеков.
- **Поддерживаемые кодеки**:
  - Видео: AV1, VP9, AVC (H.264), HEVC (H.265);
  - Аудио: EAC3 (Dolby Digital Plus / 5.1), AC3 (Dolby Digital), Opus, AAC.
- **Сквозная передача звука (Passthrough)**: Если ТВ не декодирует EAC3 аппаратно, но подключён к ресиверу или саундбару через HDMI ARC/eARC, приложение активирует сквозной вывод звука.

## 🔍 Диагностика устройства и безопасность

Инструмент диагностики помогает оценить параметры системы и выявить причины сбоев:

- **Отчёт об устройстве**: Модель ТВ, версия ОС, параметры экрана, доступные видео- и аудиодекодеры;
- **Журнал ошибок (Error Journal)**: Локальный кольцевой буфер недавних событий и сбоев (до 500 записей / 7 дней);
- **Действия**: Просмотр отчёта на экране ТВ, копирование журнала в буфер обмена и отправка отчёта разработчикам по протоколу HTTPS;
- **Идентификатор отчёта**: После успешной отправки пользователь получает уникальный номер тикета (например, `VOX-XXXXXX`);
- **Бэкенд**: Сервис приёма отчётов развёрнут на Cloudflare Workers + D1 (`https://vox-diagnostics.amn2402.workers.dev/`). Панель управления является закрытым разделом разработчика.

### Приватность диагностики (Zero-Telemetry)
- **Отсутствие скрытой телеметрии**: Данные никогда не собираются и не отправляются в фоновом режиме без явного подтверждения пользователем.
- **Гарантированное исключение PII**: В диагностические отчёты и логи категорически **не попадают**:
  - Логины, пароли и email-адреса;
  - Токены доступа (`access_token`, `refresh_token`, `id_token`, `device_code`);
  - Cookies и сессионные данные;
  - История просмотров и поисковые запросы;
  - Названия и идентификаторы просматриваемых видео;
  - Аппаратные идентификаторы: Android ID, SSAID, MAC-адреса, SSID Wi-Fi, серийные номера;
  - Учётные записи Samsung Account или Google Account;
  - Приватные криптографические ключи и подписанные URLs.
- Подробные принципы безопасности и схемы данных описаны в [docs/DIAGNOSTICS_PRIVACY.md](docs/DIAGNOSTICS_PRIVACY.md).

## 🛠 Сборка из исходников

### Android TV (APK)
Требуются JDK 17 и Android SDK (API 34, Build-Tools 30.0.3).
```bash
# Модульные тесты Android
.\gradlew.bat :common:testStvotDebugUnitTest :smarttubetv:testStvotDebugUnitTest --daemon

# Сборка отладочного APK
.\gradlew.bat :smarttubetv:assembleStvotDebug --daemon
```
Собранные APK размещаются в каталоге `smarttubetv/build/outputs/apk/stvot/debug/`.

### Samsung Tizen (WGT)
Требуется Node.js 18+.
```bash
# Модульные тесты Tizen
npm.cmd --prefix tizen test

# Сборка пакета WGT
node tizen/tools/build-wgt.js
```
Собранный WGT-артефакт создаётся в `tizen/build/SmartTube-VOX-7.0.0.wgt`.

### Сервис диагностики
```bash
# Тесты сервиса и браузерный E2E
npm.cmd --prefix services/vox-diagnostics test
```
