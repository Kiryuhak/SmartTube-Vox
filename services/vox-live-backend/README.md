# VOX Live Translation Backend

Серверный бэкенд SmartTube VOX для сквозного перевода живых трансляций (STT -> Translation -> TTS).

## Архитектура
- **STT**: Faster-Whisper (CTranslate2, инференс на CPU/GPU).
- **Translation**: Marian NMT (Opus-MT en->ru).
- **TTS**: Piper TTS (VITS, русский голос ru_RU-dmitri-medium / ru_RU-irina-medium).
- **Очереди**: Bounded FIFO с конвейерным перекрытием стадий (pipelining).
- **Память**: Эфемерные буферы (memory-only, без сохранения аудио на диск).
- **Безопасность**: Защита от перегрузок (HTTP 429), валидация PCM, короткоживущие токены сессий.

## Режимы работы
1. **MOCK** (по умолчанию): детерминированный синтез и имитация задержек для тестирования сетевой топологии и интеграционных тестов без загрузки тяжелых моделей.
2. **LOCAL_REAL**: инференс реальных локальных моделей при наличии установленных библиотек и весов.
