# SmartTube VOX Diagnostics Service

Безопасный микросервис приёма анонимных отчётов совместимости SmartTube VOX.

## Схема отчёта: `vox-diagnostic-report-v1`

Отчёт передаётся строго в формате JSON и содержит исключительно технические параметры устройства:
- Версия приложения и `versionCode` (например `32.56-vox.7-dev` / `2446007`);
- Платформа (`Android TV`, `Samsung Tizen`);
- Производитель и модель устройства;
- Поддерживаемые аппаратные видеодекодеры (`AVC`, `VP9`, `AV1`, `HEVC`);
- Аудиодекодеры и статус Passthrough (`AAC`, `OPUS`, `AC3`, `EAC3`);
- Параметры экрана и профили HDR (`HDR10`, `HLG`, `HDR10+`, `Dolby Vision`);
- Активная и рекомендованная политика кодеков VOX.

## Гарантия конфиденциальности (Privacy-First)

- **Полный запрет PII**: сервис не собирает и автоматически отклоняет запросы с полями `token`, `password`, `cookie`, `secret`, `email`, `account_id` или `authorization`.
- **Локальные IP-адреса и сессии** заменяются на `[LOCAL_IP]` и `[REDACTED]` до передачи по сети.
- **Ограничение размера**: тело запроса не может превышать 64 КБ.
- **Изолированный HTTPS-транспорт**: отправка отчёта выполняется только по прямому согласию пользователя из меню «Диагностика совместимости».

## API Endpoints

- `POST /v1/report` — приём и валидация отчёта. Возвращает уникальный идентификатор вида `VOX-XXXXXX`.
- `GET /healthz` — проверка состояния сервиса.
