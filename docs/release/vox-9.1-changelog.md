## SmartTube Vox 9.1

### Перевод (VOX Translation)
- **Стабильность перевода:** Устранено зависание на 99% («вечная загрузка перевода») благодаря адаптивной политике ожидания длинных видео (L1–L5 tiers до 14400s / 4 ч).
- **Adaptive Audio:** Добавлен адаптивный микшер громкости на базе среднеквадратичного уровня (RMS) с плавным подавлением громкости оригинальной дорожки (-16.5 dB) во время русской речи и плавным восстановлением при паузах без щелчков и клиппинга.
- **Диагностика покрытия перевода:** Внедрён трекер временной шкалы перевода (`VoxTranslationTimelineTracker`) и телеметрия `TRANSLATION_TIMELINE_COVERAGE` для контроля длительности речи, пауз и процента покрытия.
- **Индийский контент (Hinglish):** Оптимизирован приоритет выбора оригинальной аудиодорожки (`en` > `hi`) для сервиса голосового перевода, исключающий фрагментарные пропуски ASR.
- **Надёжность watchdog:** Устранено ложное срабатывание сторожевого таймера при переключении на резервный бэкенд.

### Воспроизведение (Player Recovery)
- **Автоматическое восстановление соединения:** Реализован конечный автомат ограниченного восстановления (`VoxPlaybackRecoveryPolicy`), исключающий бесконечный спиннер «Восстановление соединения» при микрообрывах сети.
- **Обработка HTTP 403 / устаревания ссылок:** При получении HTTP 403 плеер автоматически запрашивает свежий `PlayerResponse`, пересоздает `MediaSource` и возобновляет воспроизведение без перезапуска видео пользователем.
- **Ограниченное переключение DNS/движка:** Реализован защищённый переход Cronet → OkHttp с блокировкой циклических переключений (no engine loop).
- **Сохранение контекста:** При восстановлении видео сохраняется позиция воспроизведения (со смещением -2 сек для бесшовности VOD), скорость, состояние `playWhenReady`, дорожки аудио и субтитров.
- **Интерфейс ошибки:** При исчерпании лимита попыток спиннер скрывается и отображается понятный диалог «Не удалось восстановить соединение» с кнопкой «Повторить».

### Обновления (OTA System)
- **OTA Core & HUD:** Полностью обновлённый визуальный интерфейс загрузки и установки обновлений с поддержкой фоновой загрузки, индикацией прогресса и анимацией статуса.
- **Mini-HUD и восстановление:** Возможность сворачивания оверлея обновления в компактный Mini-HUD с сохранением прогресса и бесшовным разворачиванием.
- **Валидация целостности:** Двухэтапная проверка целостности пакета перед установкой (SHA-256, совместимость архитектуры ABI, подпись пакета, разрешение `REQUEST_INSTALL_PACKAGES`).
- **Изоляция каналов:** Разделение каналов Stable, Beta и изолированного тестового стенда QA.

### Диагностика и отчёты
- **Надёжная доставка Telegram:** Реализована строгая проверка квитанций доставки (delivery ack: HTTP 200 + `ok == true` + `message_id`), экспоненциальный retry и явные статусы инцидентов.
- **Безопасность данных (Safe Reporting):** Полное маскирование токенов ботов, идентификаторов чатов и URL-адресов с подписями в логах и отчетах. Исключена отправка синтетических тестовых инцидентов в продакшн.
- **Панель диагностики:** Интерактивный экран статуса и локальной проверки отправки инцидентов.

### Подтверждённые исправления
- Исправлен автоматический переход к следующему видео в ленте Shorts.
- Исправлено наложение оверлея HUD при быстрых переключениях видео.
- Добавлена нормализация окончаний строк `.gitattributes` (LF/CRLF) для кроссплатформенной разработки.
