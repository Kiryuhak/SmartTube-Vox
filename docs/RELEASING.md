# Оформление выпусков SmartTube VOX

Для версии `<версия>` подготовьте файл `docs/SMARTTUBE_VOX_<версия>_RELEASE_NOTES.md` до создания релизного тега. Первый заголовок уровня H1 становится видимым названием GitHub Release. Если H1 отсутствует, автоматизация использует название `SmartTube VOX <версия>`.

Пишите заметки **на русском языке** как подробный технический список изменений, понятный пользователю. Рекомендуемая структура:

1. `## Добавлено` — новые возможности.
2. `## Исправлено` — конкретные исправленные сценарии.
3. `## Изменено` — поведение существующих функций.
4. `## Стабильность и безопасность` — подтверждённые проверки и меры.
5. `## Установка` — файлы APK, версия и пакет.
6. `## Благодарности` — использованные проекты и ссылки на `CREDITS.md`, `NOTICE`, `LICENSE`.

При необходимости добавьте отдельный раздел «Живой голос». Не заменяйте существующий полный файл шестью рекламными пунктами: автоматизация использует его содержимое без сокращения. Краткие пункты из `CHANGELOG.md` отдельно попадают в манифест обновления приложения.
