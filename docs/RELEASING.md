# Оформление выпусков SmartTube VOX

Для версии `<версия>` подготовьте файл `docs/SMARTTUBE_VOX_<версия>_RELEASE_NOTES.md` до создания релизного тега. Первый заголовок уровня H1 становится видимым названием GitHub Release. Если H1 отсутствует, автоматизация использует название `SmartTube VOX <версия>`.

Пишите заметки **на русском языке** как краткий технический список пользовательских изменений. Стандартная структура GitHub Release:

```text
# SmartTube VOX <версия> — <краткое название>

Короткое вступление.

## Добавлено

## Улучшено

## Исправлено
```

Дополнительный раздел добавляйте только тогда, когда он действительно нужен конкретному выпуску. По умолчанию не включайте установку, благодарности, лицензионные сведения, отчёт о тестировании и аудит безопасности: эти сведения находятся в документации проекта. Автоматизация публикует весь файл заметок без добавления разделов. Краткие пункты из `CHANGELOG.md` отдельно попадают в манифест обновления приложения.
