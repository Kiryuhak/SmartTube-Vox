# Итоговая сквозная приёмка SmartTube VOX 5

Документ фиксирует результаты финальной сквозной проверки (End-to-End Acceptance) функциональности SmartTube VOX 5 на физическом телевизоре и в тестовой инфраструктуре.

---

## Среда

- **Физический телевизор**: TCL (G08, Smart TV Pro)
- **Устройство ADB**: `192.168.2.114:5555`
- **ОС / API**: Android 14 / API 34
- **Архитектура (ABI)**: `armeabi-v7a`
- **Пакет**: `io.github.kiryuhak.smarttubevot.stable`
- **Версия**: `32.56-vot.4` (code `2446004`)
- **Эмулятор**: `Vox-TV-14` (Android 14 / API 34 / `emulator-5554`)

---

## Обычное воспроизведение

- **VOD A (`dQw4w9WgXcQ`)**: Воспроизведение штатное (>15 сек), проверены пауза, возобновление, перемотка вперед (+30 сек) и назад (-10 сек). Отсутствуют ошибки `loadFormatInfo` и `SocketTimeoutException`.
- **VOD B (`jNQXAC9IVRw`)**: Воспроизведение штатное, переход в состояние `STATE_READY` без задержек.
- **Прямые трансляции (Live Streams)**: Плеер штатно воспроизводит активные прямые эфиры. Кнопка скачивания возвращает понятное предупреждение о неподдерживаемости прямых трансляций без падений приложения.
- **Shorts**: Воспроизведение коротких видео проходит без сбоев.

---

## Standard VOX

- **Запуск перевода**: Закадровый перевод на поддерживаемых англоязычных видео стартует без дублирования запросов.
- **Синхронизация**: Пауза, возобновление и перемотка видео синхронизируют дорожку перевода.
- **Переключение видео**: При смене контента предыдущие сессии перевода очищаются, утечек аудиопотоков нет.
- **Приглушение звука (Audio Ducking)**: Уровень оригинального звука восстанавливается корректно при остановке или завершении перевода.

---

## Живой голос

- **Авторизация**: Токены и состояние авторизации сохраняются между перезапусками приложения (`am force-stop`).
- **Переключение режимов**: Переключение между `Standard` и `Lively` режимами функционирует стабильно.
- **Отсутствие авторизации**: При отсутствии токенов система явно сообщает о необходимости авторизации без скрытого искажения настроек.

---

## Внешний запуск

- **DIAL HTTP-сервер**: Включение настройки «Внешний запуск видео» поднимает локальный легковесный HTTP-сервер на Kotlin (порт 8081).
- **Запуск видео**: Внешний POST-запрос с `videoId` и меткой времени `t` корректно открывает видео в плеере.
- **Дедупликация**: Повторные идентичные запросы в окне 3 секунды подавляются (`DEDUP_WINDOW_MS = 3000L`).
- **Безопасность**: Запросы из ненадежных внешних диапазонов или с некорректным телом отклоняются (HTTP 403 / 400 / 413).
- **Отключение**: При выключении настройки сокет сервера закрывается.

---

## Скачивание

- **Интерфейс**: В меню плеера доступно действие «Скачать с переводом» с диалогом выбора качества (360p, 720p, 1080p) и режима перевода.
- **Этапы загрузки**: В UI отображаются русскоязычные статусы без внутренних терминов («Подготовка перевода», «Загрузка видео», «Загрузка оригинального звука», «Загрузка перевода», «Упаковка файла», «Сохранение файла», «Готово»).
- **Дедупликация**: При попытке повторного скачивания отображается диалог «Видео уже скачано» с вариантами «Открыть», «Скачать ещё раз», «Отмена».

---

## Фон

- **Кнопка HOME**: При сворачивании приложения на домашний экран сервис `VoxDownloadService` продолжает загрузку в режиме `FOREGROUND_SERVICE_TYPE_DATA_SYNC`.
- **Прогресс**: За 60 секунд нахождения на домашнем экране ТВ размер скачиваемого потока стабильно растет.
- **Уведомление**: Системное уведомление отображает текущий прогресс, этап и кнопку отмены.

---

## Восстановление

- **Принудительное завершение (`force-stop`)**: При завершении процесса задача переходит в состояние `PAUSED`, частично загруженные файлы (`.part`) сохраняются.
- **Возобновление (Resume)**: При вызове возобновления скачивание продолжается по HTTP Range-запросам без перезагрузки уже полученных байтов.

---

## MKV

- **Мультиплексор Matroska (MKV)**: Чистый Kotlin-ремультиплексор без FFmpeg и GPL-зависимостей объединяет AVC-видео, AAC-оригинал и MP3-перевод.
- **Заголовок и дорожки**: Сгенерированный файл содержит Matroska Header (`1A 45 DF A3`), дорожку перевода по умолчанию (`ru`) и оригинальную аудиодорожку (`und`).
- **Публикация MediaStore**: Файл публикуется в `Movies/SmartTube VOX/` с MIME-типом `video/x-matroska` и флагом `IS_PENDING=0`.

---

## Офлайн

- **Локальное воспроизведение**: Плеер открывает скачанный MKV-файл локально (`isLocal=true`).
- **Изоляция сети**: Во время локального воспроизведения количество запросов к Yandex Translation API и YouTube InnerTube API равно нулю.
- **Управление**: Проверены переключение аудиодорожек («Перевод» ↔ «Оригинал»), перемотка (30с, 60с, назад), пауза/возобновление и завершение файла (EOS).

---

## Ошибочные сценарии

- **Прямые трансляции**: Отклоняются с понятным сообщением.
- **Недостаточно места**: При нехватке хранилища выдается ошибка `INSUFFICIENT_STORAGE` без создания поврежденных файлов.
- **Небезопасные имена**: Символы path traversal и недопустимые спецсимволы в названиях видео безопасно санируются.
- **Отмена**: Отмена скачивания очищает временные `.part` и `.tmp` файлы и останавливает сервис.

---

## Производительность

- **Память (PSS)**: Пиковое потребление памяти в процессе загрузки и слияния составляет ~223 МБ, утечек и OOM не зафиксировано.
- **Остановка сервиса**: После завершения скачивания `VoxDownloadService` штатно останавливается, фоновые потоки освобождаются.

---

## Безопасность

- **Секреты и токены**: В кодовой базе и логах отсутствуют подписанные URL, OAuth-токены и приватные ключи.
- **Изоляция компонентов**: `VoxDownloadService` объявлен с `android:exported="false"`.
- **Релизный манифест**: Тестовый приемник `YandexVotTestReceiver` отсутствует в релизных сборках (`stvotRelease` и `ststableRelease`).

---

## Ограничения

- Скачивание прямых трансляций (Live Streams) не поддерживается технически.
- Поддерживаемый формат сборки без транскодирования — Matroska (.mkv) с потоками AVC/H.264, AAC и MP3.
