# SmartTube VOX 32.47-vot.2 — Примечания к выпуску (Release Notes Draft)

## Обзор версии
Версия **SmartTube VOX 32.47-vot.2** (сборка `2437002`) является плановым обновлением стабильной ветки на базе апстрима SmartTube `32.47`. Релиз сфокусирован на кардинальном повышении надёжности механизма закадрового перевода Yandex VOT, устранении сетевых зависаний при поллинге, стабилизации обработки ошибок и улучшении безопасности диагностического логирования.

---

## Ключевые изменения и улучшения

### 1. Надёжность Yandex VOT и исправление длительного ожидания
- **Улучшенный цикл опроса (Polling)**: Устранены зависания и преждевременные обрывы опроса готовности аудиодорожки перевода после получения начального статуса ожидания (`STATUS_WAITING`).
- **Сохранение и отображение ETA**: Корректный учёт расчётного времени готовности перевода (`remainingTime`) с непрерывным обратным отсчётом в индикаторе статуса.
- **Безопасные повторные попытки (Safe Retries)**: Реализована устойчивая обработка временных сетевых ошибок ввода-вывода (IO/Socket/Timeout) при опросе сервера. Временные сбои сети больше не сбрасывают состояние подготовки перевода и обрабатываются управляемыми повторами.
- **Корректная классификация `STATUS_FAILED`**: Чёткое разделение серверных отказов (ошибки генерации перевода на стороне бэкенда) и сетевых сбоев, что исключает зацикливание невыполнимых запросов.
- **Предотвращение дублирующих уведомлений**: Исключено многократное появление всплывающих сообщений и тостов об ошибках при серии повторных сетевых запросов.

### 2. Безопасность и диагностика
- **Безопасное диагностическое логирование**: Внедрена строгая санитизация журналов: подписи, токены сессий и прямые ссылки на аудиопотоки (`MP3 URL`) полностью маскируются в логах.
- **Отсутствие HTTP Body в релизных логах**: Тела сетевых запросов и ответов исключены из стандартного логирования для защиты пользовательских данных.

### 3. Пользовательский интерфейс и воспроизведение
- **Сохранение оригинального Leanback UI**: Классический телевизионный интерфейс SmartTube сохранён в полном объёме. Экспериментальные редизайны исключены.
- **Кнопка перевода и индикатор**: Кнопка перевода стабильно доступна на панели управления воспроизведением (верхний ряд действий плеера). Компактный индикатор ожидания и статуса отображается в правом нижнем углу экрана.
- **Синхронизация и дакинг звука**: При переходе перевода в статус `ACTIVE` уровень громкости оригинальной дорожки плавно приглушается (audio ducking), а рассинхронизация звуковой дорожки перевода автоматически компенсируется с минимальной дельтой.

### 4. Яндекс ID и статус режимов
- **Диагностика авторизации Яндекс ID**: Проведена глубокая ревизия и структурирование подсистемы авторизации.
- **Ограничение Device Code Flow**: Авторизация по коду устройства (Device Code Flow) остаётся в режиме экспериментальной диагностики и пока не является полностью завершённой для конечного пользователя.
- **Режим Lively**: Для режима Lively требуется действующая сессия авторизации Яндекс ID. В тестовой среде без авторизации режим переходит в статус `BLOCKED — NO AUTH SESSION` (не является регрессией стандартного перевода).
