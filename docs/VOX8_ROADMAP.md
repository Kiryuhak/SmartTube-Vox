# SmartTube VOX 8 — Дорожная карта разработки (Roadmap)

Данный документ определяет ключевые направления, приоритеты и ориентировочный план патчей цикла разработки **SmartTube VOX 8**.

---

## 1. Приоритеты разработки

### P0 — Translation 2.0 (Закадровый перевод нового поколения)
- Архитектурный аудит и подготовка инфраструктуры для **Live Translation** (прямые трансляции);
- Клиентский буфер задержки (Dynamic Delay Buffer) и контроллер синхронизации для потокового перевода;
- Повышение стабильности обычного VOD-перевода при сетевых сбоях и резких перемотках;
- Автоматическое восстановление аудиосессий при переподключении;
- Улучшение точности синхронизации звука и видео на всех скоростях воспроизведения.

### P1 — Downloads 2.0 (Расширенный менеджер загрузок)
- Поддержка очереди последовательных и параллельных загрузок;
- Полноценная пауза и возобновление (pause/resume) без потери уже скачанных фрагментов;
- Управление несколькими активными задачами скачивания в интерфейсе;
- Автоматическая и надежная очистка временных и незавершенных файлов;
- Полировка интерфейса раздела «Скачанные видео» и информативных карточек.

### P1 — Auto Setup 2.0 (Адаптивная автонастройка)
- Учет не только статических флагов аппаратных декодеров, но и реальной статистики выпадения кадров (dropped frames);
- Мониторинг стабильности и производительности кодеков в динамике;
- Автоматический выбор оптимального и стабильного профиля воспроизведения при обнаружении подтормаживаний.

### P1 — Android Compatibility (Расширенная совместимость)
- Сквозные runtime-проверки и адаптация логики для Android TV на версиях от API 28 (Android 9) до API 34 (Android 14).

### P1 — Samsung Tizen OS
- Развертывание и интеграция инструментов Tizen Studio и TV Extension;
- Отладка на Tizen TV Emulator;
- Проверка установки WGT-пакетов, обработки клавиш DPAD и жизненного цикла веб-приложения;
- Интеграция диагностических отчетов и сканирования аппаратных возможностей Tizen.

### P2 — Diagnostics 2.0 (Интеллектуальная диагностика)
- Улучшенная серверная группировка одинаковых типов ошибок в админ-панели;
- Прямая привязка reportId к номеру патча и конкретному билду;
- Ускоренная фильтрация и пакетный экспорт отчетов разработчику.

### P2 — Performance & Optimization (Производительность)
- Ускорение времени холодного и теплого старта главной страницы (Home startup);
- Оптимизация потребления оперативной памяти и устранение потенциальных утечек;
- Сокращение дублирующих сетевых запросов;
- Стабилизация работы фоновых воркеров при длительном непрерывном воспроизведении.

### P2 — UI Polish & UX (Полировка интерфейса)
- Обновление элементов HUD и экранного оверлея плеера;
- Дальнейшее улучшение бейджей качества и длительности;
- Реализация экрана «Что нового» при обновлении приложения;
- Расширение пользовательских настроек оформления интерфейса.

## 2. Ориентировочный план патчей (Patch Plan)

| Патч | Название / Фокус |
|:---:|---|
| **Patch #1** | **Foundation**: Старт цикла VOX 8, перевод на `32.56-vox.8-dev`, фиксация Release Policy и Roadmap (MERGED) |
| **Patch #2** | **Translation 2.0**: Архитектурный аудит подсистемы перевода, сессионная модель и синхронизация (MERGED) |
| **Patch #3** | **Live Translation**: Исследование протокола, анализ Yandex VOT API (VOD_ONLY) и отказ от фейков (MERGED) |
| **Patch #4** | **Live Playback Stability**: Устранение причин периодического зависания спиннера, Dash 404 policy, стратегия Controlled Live Backend (MERGED) |
| **Patch #5** | **Live Ingestion Gateway**: Реализация Controlled Live Ingestion Gateway, REST API, адаптивный контроллер сегментов, Mock provider (MERGED) |
| **Patch #6** | **Live Audio Capture & PTS Sync**: Захват фрагментов из аудиотракта и вторичный AudioTrack с синхронизацией по PTS (MERGED) |
| **Patch #7** | **User Feedback & Downloads Reliability**: Устранение инцидента VOX-A-DF6567 (DuneHD), надежность загрузок (Diagnostics 2.0, типизированные ошибки, упаковка MKV), исправление фокуса и сортировки каналов (MERGED) |
| **Patch #8** | **Live Provider Strategy & Audio Integration**: Исследование провайдеров, аудит Yandex VOT (VOD_ONLY), стандартизация контракта провайдера, детерминированный аудио-ресемплер и маршрутизация шлюза (MERGED) |
| **Patch #10** | **Downloads 2.0 Performance & Local Real Live Translation Backend Prototype**: Ускорение загрузок (буферизация, connection pooling, троттлинг, параллельные потоки, Range resumption) и подготовка локального бэкенда инференса с честным профилированием хост-машины (MERGED) |
| **Patch #11** | **Android Compatibility**: Runtime-тестирование API 28–34 |
| **Patch #12** | **Tizen Emulator**: Тестирование жизненного цикла и WGT на Tizen TV Emulator |
| **Patch #13** | **Diagnostics 2.0 Cloud**: Группировка инцидентов и привязка к версиям/патчам на сервере |
| **Patch #14** | **Performance & UI Polish**: Оптимизация памяти, полировка оверлея, бейджей и экрана «Что нового» |
| **Далее** | Корректировки и доработки на основе реальной диагностики и обратной связи |
