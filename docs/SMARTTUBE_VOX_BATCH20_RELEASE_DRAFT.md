# SmartTube VOX — локальный черновик релиза

Статус: подготовка к финальной приёмке, публикация не выполнялась.

## Базовая точка

- Ветка: `fix/yandex-auth-diagnostics`
- HEAD: `58c8bd77`
- Версия приложения: `32.47-vot.1`
- Package: `io.github.kiryuhak.smarttubevot.stable`
- PR #16: открыт, не изменён

## Реализовано

- VOT Standard с сохранением штатного пути перевода.
- VOT Lively с отдельным состоянием авторизации Яндекс ID.
- Ручной ввод OAuth-токена с проверкой формата и сохранением существующего токена при ошибочном вводе.
- Device Code Flow для показа кода на TV, отмены, обновления и защиты от устаревших callback-ов.
- Обработка `401`, `403`, `429`, `5xx`, сетевых ошибок и `invalid_client` без утечки токенов в логи/UI.
- Синхронизация перевода с запуском, остановкой, сменой видео, паузой, перемоткой и изменением скорости.
- Защита от устаревших запросов и ответов.
- Кнопка перевода в штатном интерфейсе плеера.
- VOX-only полный сброс через системный API с подтверждением.
- Сохранение оригинального интерфейса SmartTube без экспериментального редизайна.

Установка и запуск не заменяют функциональную TV-приёмку. Визуальная проверка, обычное видео, LIVE, Standard и Lively на TV ещё не подтверждены.

## Ограничения и блокеры

- Device Code Flow ранее возвращал `invalid_client` / `Wrong client secret`. Безопасное решение пока не подтверждено; автоматический вход по коду не считается успешно работающим.
- `client_secret` нельзя встраивать в Android APK и нельзя добавлять OAuth proxy.
- Реальная OAuth-авторизация и фактическая работа Lively на TV не подтверждены.
- До публикации нужны ручная TV-приёмка, проверка release-артефактов и отдельное решение владельца о публикации.

Существующие исторические release-документы относятся к другим HEAD/версиям и не являются подтверждением текущего статуса. Этот файл — локальный черновик для `58c8bd77`.
