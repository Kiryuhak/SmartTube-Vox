# Менеджер загрузок VOX 6

## Цель

Показать сохранённые задания и дать управление ими с пульта Android TV. Источник данных — существующие `job.json` и `VoxDownloadRepository`.

## Точка входа

Карточка «Загрузки VOX» находится в сетке настроек только варианта STVOT. Используется штатный `AppDialogPresenter`; боковая панель и отдельная Activity не нужны.

## Состояния

Список группируется по активным, приостановленным, ошибкам, готовым и отменённым заданиям. Пустые группы скрываются. Активные идут первыми; внутри группы записи сортируются по времени создания. Процент показывается лишь при известных объёмах. Для готовых файлов проверяется доступность URI; при внешнем удалении файла показывается «Файл удалён».

## Действия

Активное задание открывает существующий диалог прогресса либо отменяется с подтверждением. Приостановленное возобновляется через `VoxDownloadService.resume`. Ошибочное или отменённое запускается как новое задание, старые метаданные удаляются. Готовый файл открывается через `VoxLocalPlayerHelper`; повторная загрузка открывает обычный выбор качества и перевода.

## Фоновые загрузки

Экран подписывается на события координатора, пока открыт, и снимает подписку при закрытии. Частые события прогресса сводятся к изменениям десятков процентов. Закрытие экрана не останавливает сервис.

## Хранилище

Сводка складывает размер файлов только в каталогах заданий и размер сохранённых URI, затем показывает свободное место через `StatFs`. Расчёт выполняется в фоновом потоке. Запросы URI выполняются один раз на обновление списка.

## Ошибки

Основной экран показывает понятные русские описания по `VoxDownloadErrorCode`, без сырых исключений и HTTP-кодов.

## Удаление

Готовый файл удаляется через MediaStore с подтверждением, затем удаляются метаданные и внутренние файлы. При ошибке удаления доступного опубликованного файла запись сохраняется. Активную задачу нельзя удалить из-под исполнителя: сначала предлагается отменить загрузку.

## Android TV UX

Пункты списка и действия используют штатные фокусируемые элементы SmartTube. Кнопка BACK закрывает интерфейс без отмены фоновой загрузки. Отсутствие записей обозначено явным текстом.

## Ограничения

Массовое удаление, поиск, фильтры и дополнительные кодеки оставлены для следующих патчей. Сводка свободного места относится к разделу временных файлов; если MediaStore находится на другом томе, его свободное место может отличаться.

## Проверки

Unit-тесты покрывают группировку, сортировку, действия, подписи, отсутствие выдуманного процента и арифметику размера. Сборки STVOT и стандартного варианта проверяются отдельно. Приёмка на физическом телевизоре отложена по плану спринта.
