# SmartTube VOX 7 — Интерфейс, загрузки и качество воспроизведения (Patch #4)

## Скачанные видео

- **Расположение**: Раздел «Скачанные видео» интегрирован в главное боковое меню (`SidebarService`, `BrowsePresenter.TYPE_DOWNLOADED`).
- **Сетка материалов**:
  - Карточки отображают обложку, длительность, размер файла и статус.
  - По нажатию (D-Pad Center) — запуск локального воспроизведения через `VoxLocalPlayerHelper`.
  - При отсутствии видео отображается дружелюбное состояние: «Нет скачанных видео».
  - Обработка удалённых извне файлов: статус «Файл удалён», предотвращение сбоев воспроизведения.
- **Управление**:
  - Долгое нажатие на карточку открывает контекстное меню действий: «Воспроизвести», «Удалить», «Удалить все скачанные видео».
  - Массовое удаление сопровождается подтверждением («Удалить все скачанные видео?»).
- **Поведение после просмотра**:
  - Опция в настройках: «После просмотра скачанного видео» (`Ничего не делать` / `Предлагать удалить`).
  - Диалог удаления активируется строго для локальных видео (`video.isLocal`) в `VideoLoaderController`.

## Кнопка Скачать

- **Интеграция**: Кнопка «Скачать с переводом» добавлена в контекстное меню карточки видео (`VideoMenuPresenter`).
- **Состояния**:
  - Динамическое отображение статуса («Скачать», «Скачивание... N%», «Скачано»).
  - Защита от повторного запуска параллельной загрузки того же ролика.
  - Уведомление пользователя о постановке в очередь и прогрессе.

## Хранилище

- **Контроль свободного места**:
  - Перед стартом загрузки выполняется проверка порога свободного места на носителе (<300 МБ).
  - При нехватке памяти отображается предупреждение с возможностью перехода в раздел «Скачанные видео» для очистки.
- **Очистка данных**:
  - Безопасное удаление видеофайла и метаданных без повреждения файловой структуры.

## Бейджи

- **Качество потоков**:
  - Бейджи качества (`4K`, `2K`, `FHD`, `HD`, `SD`) отображаются поверх превью карточек видео (`VoxBadgeHelper`).
  - Фильтрация пустых/неопределённых значений (`0p`, `Auto`, `null`).
  - Отсутствие дополнительных сетевых запросов при отрисовке ленты — данные извлекаются из готовых метаданных видео.
- **Корректность сетки**:
  - Бейджи не ломают выравнивание и пропорции карточек в `ComplexImageCardView`.

## Возрастные ограничения

- **Обработка защищённого контента**:
  - Видео с возрастными ограничениями (18+) и приватные потоки обрабатываются с информативными сообщениями об ошибке без падений приложения.
  - Сохранение стабильности загрузчика при невозможности извлечения потока.

## Прокси

- **Селективная маршрутизация**:
  - Настройки прокси (`HTTP` / `SOCKS5`) вынесены в `PlayerSettingsPresenter` -> «Закадровый перевод (Яндекс)».
  - Прокси применяется исключительно к доменам Яндекса (`api.browser.yandex.ru`, `vtrans.s3.yandex.net`, `oauth.yandex.com`).
  - Прямой трафик YouTube (видеопотоки, метаданные, обложки) не затрагивается.
- **Отказоустойчивость (Fail-Closed)**:
  - При недоступности прокси запросы к Яндексу не утекают в открытую сеть, а возвращают контролируемую ошибку.

## Авторизация

- **Единая точка входа**:
  - В меню настроек отображается единая кнопка входа («Войти через Яндекс ID» / «Переавторизоваться» / «Яндекс ID: Авторизация сохранена»).
  - Исключены дублирующие кнопки.
  - Отображение статуса: «Авторизация сохранена», «Не авторизован», «Ошибка авторизации».
- **Ручной ввод**:
  - Пункт «Ввести токен вручную...» позволяет задать токен напрямую при отсутствии брокера.

## DPAD

- **Навигация с пульта TV**:
  - Полноценная поддержка пульта дистанционного управления: перемещение фокуса, скролл списков, вызов контекстных меню по долгому нажатию.
  - Предсказуемое поведение кнопки «Назад» (Back): закрытие диалогов, возврат из разделов на главный экран.

## 4K/FPS аудит

- **Аппаратные возможности**:
  - Определение поддерживаемых кодеков (VP9, AV1, AVC) через `DeviceHelpers` и `MediaCodecList`.
  - Возможность принудительного разблокирования всех форматов («Разблокировать все форматы») в настройках плеера.
  - Настройки пресетов качества («Video presets») и Auto Frame Rate (AFR) доступны в полном объёме.

## Autoplay

- **Разделение логики**:
  - Автовоспроизведение превью на карточках главной ленты (`MainUIData.getCardPreviewType()`) полностью изолировано от автовоспроизведения рекомендаций следующего видео в плеере (`SuggestionsController`).

## Известные ограничения

- Загрузка длинных трансляций (стримов) требует достаточного объёма свободного хранилища.
- В режиме селективного прокси скорость загрузки аудиодорожки перевода зависит от пропускной способности используемого прокси-сервера.
