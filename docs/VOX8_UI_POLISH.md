# SmartTube VOX 8 — Отчёт о полировке интерфейса (UI/UX Polish)

Документ фиксирует изменения, доработки и результаты проверки пользовательского интерфейса SmartTube VOX 8 перед подготовкой Release Candidate.

---

## 1. Что исправлено (Applied Improvements)

### 1.1. Группы каналов (Channel Groups)
- **Форматирование счетчика каналов**: Заменено некорректное окончание `%d каналов` на нейтральную и грамматически корректную форму `Каналов: %d` (корректно отображается для любых чисел: 1, 2, 5, 20).
- **Локализация ошибок при создании и переименовании**: Исключен вывод "сырых" английских сообщений исключений Java/Kotlin. При ошибках валидации или хранилища выводятся понятные русские сообщения:
  - «Группа с таким названием уже существует»;
  - «Название не может быть пустым»;
  - «Название не может превышать 50 символов»;
  - «Не удалось сохранить группу каналов».
- **Динамический заголовок раздела «Каналы»**: При фильтрации по группе заголовок раздела автоматически принимает вид `Каналы • <Название группы>`. При сбросе возвращается `Каналы`.
- **Контекстное меню карточки канала**: Добавлен быстрый пункт «Удалить из группы «%s»» при активном фильтре выбранной группы, что избавляет от необходимости открывать вложенные диалоги.

### 1.2. Диагностика и логи (Diagnostics UI)
- **Упрощение формулировок**: Заменены технические термины на понятные для пользователя:
  - «Отправить разработчику» вместо «Send diagnostic telemetry»;
  - «Журнал ошибок» вместо «Internal log buffer»;
  - Четкий диалог согласия на отправку анонимных данных с перечислением того, что передается, и гарантией отсутствия персональных данных, паролей и токенов.

### 1.3. Менеджер загрузок (Downloads 2.0 UI)
- **Сглаживание скорости и ETA**: Использование алгоритма EMA (Exponential Moving Average) с 3-секундным периодом прогрева предотвращает скачки скорости и показ нереалистичного оставшегося времени.
- **Предотвращение артефактов**: Значения прогресса строго ограничены диапазоном `0..100%`, исключены отрицательные значения скорости и зависания на отметке 99%.
- **Понятные описания этапов**: Этапы «Скачивание видео», «Скачивание звукового перевода», «Объединение дорожек (MKV)» отображаются на чистом русском языке без технических параметров кодеков.

### 1.4. Автонастройка (Auto Setup 2.0)
- **Краткие и емкие подписи режимов**:
  - `Автоматически`
  - `Максимальное качество`
  - `Максимальная совместимость`
  - `Пользовательский`
- Отсутствие слишком длинных пояснений, вызывающих горизонтальное обрезание строк на экранах с низким разрешением (720p).

### 1.5. Навигация DPAD и фокус (TV Remote Interaction)
- Устранены проблемы потери фокуса при выходе из диалогов редактирования названия группы.
- Подтверждено отсутствие "красного" артефактного фокуса и зависших оверлеев при быстрых перемещениях по спискам карточек.

---

## 2. Что оставлено без изменений (Preserved by Design)

- **Структура главного бокового меню (Sidebar)**: Пользовательские группы каналов не выносятся в боковое меню отдельными кнопками, чтобы не перегружать панель навигации (управление сосредоточено внутри экрана «Каналы»).
- **Оригинальные YouTube-подписки**: Добавление и удаление каналов из локальных групп VOX изолировано и принципиально не затрагивает аккаунт YouTube (не вызывает `subscribe`/`unsubscribe`).
- **Сортировки каналов**: Все 4 режима сортировки каналов (по умолчанию, по новому контенту, по имени, по последнему просмотру) сохранены и бесшовно применяются к отфильтрованным спискам групп.

---

## 3. Известные ограничения (Known Limitations)

- **Ввод текста на старых ТВ без клавиатуры Leanback**: На устройствах Android 5–7 без установленной системной виртуальной клавиатуры ввод названия группы может требовать физической клавиатуры или приложения Android TV Remote.
- **Длина названия группы**: Ограничена 50 символами для предотвращения выхода текста за границы карточек и диалогов.
