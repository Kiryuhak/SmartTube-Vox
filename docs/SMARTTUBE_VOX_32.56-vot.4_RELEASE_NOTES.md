## Добавлено

- Автоматический вход в Яндекс ID по коду на экране.
- Поддержка авторизации для «Живого голоса».
- Безопасное сохранение авторизации между запусками приложения.

## Улучшено

- Стабильность перевода Яндекса при паузе, перемотке и смене роликов.
- Синхронизация перевода при задержке его подготовки.
- Работа перевода при переключении между Standard VOX и «Живым голосом».
- Обработка повторных запросов Яндекса на подготовку исходного аудио.

## Исправлено

- Зависание и скачки счётчика ожидания перевода.
- Ситуация, когда перевод запускался после того, как видео уже ушло далеко вперёд.
- Возможные повторные загрузки исходного аудио.
- Утечки старых сессий перевода после смены ролика.
- Некорректное восстановление громкости после остановки перевода.
