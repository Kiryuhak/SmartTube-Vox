# SmartTube VOX — TV acceptance checklist

Проверять вручную на физическом Android TV после установки APK поверх текущего приложения. Не выполнять сброс данных и не менять аккаунты без отдельного разрешения владельца.

## Базовый интерфейс

- [ ] Главное меню и экран настроек выглядят как штатный SmartTube.
- [ ] Оригинальный HUD и шкала времени отображаются корректно.
- [ ] D-pad перемещает фокус предсказуемо.
- [ ] BACK возвращает на предыдущий экран и закрывает диалоги.

## Видео и плеер

- [ ] Обычное видео запускается и продолжает воспроизведение.
- [ ] LIVE-видео открывается без зависания.
- [ ] Прогресс-бар отображается.
- [ ] Pause/resume работает.
- [ ] Перемотка вперёд/назад работает.
- [ ] Изменение скорости не ломает воспроизведение.
- [ ] Переход к следующему видео работает.

## VOT

- [ ] Кнопка перевода присутствует в штатных контролах.
- [ ] Standard: запуск, остановка и повторный запуск работают.
- [ ] Standard: пауза и перемотка во время ожидания/воспроизведения не ломают состояние.
- [ ] Standard: смена видео корректно отменяет предыдущий запрос.
- [ ] Lively можно выбрать при наличии действующей авторизации.
- [ ] Lively не включается без подтверждённой авторизации.
- [ ] Ошибки сети/сервера показываются понятным сообщением без токена или технического секрета.

## Яндекс ID

- [ ] Экран Яндекс ID открывается из настроек.
- [ ] Ручной ввод токена доступен.
- [ ] Некорректный ручной ввод не заменяет действующий токен.
- [ ] Device Code Flow показывает экран кода.
- [ ] `invalid_client` не приводит к бесконечному polling и предлагает ручной ввод.
- [ ] Успешный автоматический вход по коду не считать подтверждённым без фактического успешного сценария.

## Сброс

- [ ] Пункт «Сброс настроек» присутствует рядом с «О приложении».
- [ ] Диалог содержит понятное предупреждение.
- [ ] BACK и «Отмена» закрывают диалог без сброса.
- [ ] Подтверждение сброса **не нажимать** без отдельного разрешения владельца.

## Результат

- Проверено локально: unit-тесты, сборки, статический аудит.
- Подтверждено на TV: только установка и запуск до `BrowseActivity`.
- Ожидает ручной проверки: пункты выше.
- Внешний блокер: неподтверждённый Yandex Device Code `invalid_client`.
