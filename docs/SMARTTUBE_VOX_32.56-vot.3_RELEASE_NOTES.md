# SmartTube VOX 32.56-vot.3

Неофициальная версия SmartTube для Android TV и Google TV с улучшенным закадровым переводом Яндекса.

## Что нового

- Улучшены перевод Яндекса и «Живой голос».
- Перевод может подготавливаться для роликов, где готовой озвучки ещё нет.
- Озвучка точнее следует за видео при паузе, перемотке и изменении скорости.
- Улучшены переключение между роликами, обработка сетевых ошибок и восстановление обычного звука после остановки перевода.
- Если новый способ перевода не сработал до начала воспроизведения, приложение автоматически пробует предыдущий стабильный способ.
- Добавлены варианты отображения времени; настройки перевода стали понятнее.

## Установка и обновление

Скачайте APK из [GitHub Releases](https://github.com/Kiryuhak/SmartTube-Vox/releases). Для многих старых или 32-битных устройств нужен `armeabi-v7a`, для 64-битных — `arm64-v8a`; если сомневаетесь, выберите более крупный `universal`. `x86` предназначен главным образом для эмуляторов. При обновлении более ранней сборки с тем же пакетом и ключом подписи APK можно установить поверх неё.

Обычный перевод может работать без Яндекс ID. Для «Живого голоса» войдите в SmartTube и Яндекс ID. Путь для ручного входа: **Настройки → Плеер → Закадровый перевод (Яндекс) → Войти в Яндекс**.
