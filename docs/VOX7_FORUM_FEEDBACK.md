# SmartTube VOX 7 — Patch #8: Консолидированные отзывы форума и улучшения UX/плеера

## 1. Обзор изменений

В рамках Patch #8 проанализированы и устранены 6 ключевых замечаний и пожеланий пользователей с форума:

1. **Заметность раздела загрузок (Download Discoverability)**:
   - Раздел «Скачанные видео» закреплён и доступен в боковом меню (`SidebarService`) и в виде плитки в Настройках приложения (`AppDataSourceManager`).
   - Добавлены понятные подсказки в пустом состоянии («Скачанных видео пока нет. Откройте видео и выберите «Скачать»»).

2. **Кнопка скачивания в интерфейсе плеера (Player HUD Download Button)**:
   - В оверлей управления плеером (`VideoPlayerGlue`) добавлена кнопка «Скачать» с вектором `action_download.xml` и поддержкой состояний:
     - `0`: «Скачать» (по умолчанию)
     - `1`: «Загрузка идёт» (во время активной загрузки)
     - `2`: «Скачано» (при наличии готового файла)
   - Добавлен контроллер `VoxDownloadPlayerController`, слушающий `VoxDownloadCoordinator` в реальном времени.
   - Добавлена настройка включения/выключения кнопки в «Настройки -> Плеер -> Настройка кнопок плеера» (`PLAYER_BUTTON_DOWNLOAD = 1 << 29`), включена по умолчанию для сборки VOX.

3. **Единый путь скачивания (How-To-Download Path)**:
   - Скачивание доступно как из контекстного меню карточки видео («Скачать с переводом»), так и из оверлея плеера (кнопка скачивания).
   - В обоих случаях запускается `VoxDownloadDialogHelper`, проверяющий статус (активна ли загрузка, уже скачано, либо выбор качества и дорожки).

4. **Аудит и распознавание кодеков AC3 / EAC3 / Opus**:
   - В утилите `TrackSelectorUtil` расширено распознавание кодеков: добавлены паттерны `ac-3`, `ac3`, `ec-3`, `eac3`, `opus`, `mp4a` для корректного отображения и выбора звуковых дорожек.
   - ExoPlayer использует системный `MediaCodecAudioRenderer` и `DefaultAudioSink` для сквозного вывода (Passthrough) при наличии HDMI-ресивера, либо декодирования в PCM / переключения на AAC/Opus при отсутствии аппаратного декодера Dolby.

5. **Надёжность закадрового перевода VOX («Работает только ~10% видео»)**:
   - **Первопричина**: в `VoiceTranslateController` исходный язык `sourceLang` принудительно выставлялся в `"en"`, что ломало перевод для видео на других языках (немецкий, французский, испанский, японский и др.) или без явного тега языка аудиодорожки.
   - **Решение**: fallback изменён на пустую строку `""` / автоопределение (`auto`), что позволяет Yandex API автоматически определять язык речи на бэкенде.
   - Добавлена детальная классификация ошибок `VotErrorCategory` (`AUTH_REJECTED`, `NETWORK_ERROR`, `SERVER_UNAVAILABLE`, `RATE_LIMITED`, `UNSUPPORTED_VIDEO`, `TIMEOUT`, `ACCESS_DENIED`) с показом пользователю точных локализованных сообщений.

6. **Режимы онлайн-чата YouTube (Live Chat Modes)**:
   - В `ChatController` и `PlayerData` добавлено переключение режимов чата: «Интересные сообщения» (`CHAT_MODE_TOP`) и «Все сообщения» (`CHAT_MODE_LIVE`).
   - Настройка доступна по долгому нажатию на кнопку чата в плеере с немедленным перезапуском поллера и сбросом предыдущего состояния.
