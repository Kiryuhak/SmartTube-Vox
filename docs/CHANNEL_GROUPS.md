# SmartTube VOX 8 — Локальные группы каналов (Channel Groups)

## 1. Назначение и концепция

Пользовательская функция **«Группы каналов» (Custom Channel Groups / Collections)** позволяет организовывать каналы в удобные локальные категории внутри SmartTube VOX:
* Новости;
* Технологии;
* Музыка;
* Игры;
* Обучение;
* Детям;
* Позже посмотреть каналы и др.

### Ключевые принципы архитектуры:
1. **Полная изоляция от подписок YouTube**:
   - Добавление канала в группу, удаление из группы или удаление всей группы **НИКОГДА** не вызывает методы API YouTube `subscribe` / `unsubscribe`.
   - Ваши официальные подписки на аккаунте YouTube остаются нетронутыми.
2. **Чистое боковое меню (No Sidebar Clutter)**:
   - Созданные группы не создают отдельные кнопки на боковой панели (sidebar).
   - Точка входа находится непосредственно внутри раздела **«Каналы»** (`MediaGroup.TYPE_CHANNEL_UPLOADS`).
3. **Мультигрупповая принадлежность**:
   - Один канал может одновременно входить в несколько разных групп (например, «Технологии» и «Новости»).
4. **Безопасная сохранность данных**:
   - Группы и привязки сохраняются локально в профиле пользователя (`AppPrefs.getProfileData`) в формате JSON v1 с защитой от повреждения данных.
   - При переключении профилей (аккаунтов) группы каналов переключаются автоматически.
5. **Абсолютная конфиденциальность (Zero PII)**:
   - В журнал диагностики попадают только обезличенные технические события (`CHANNEL_GROUP_CREATED`, `CHANNEL_GROUP_MEMBER_ADDED` и т.д.) со счетчиками. Названия каналов, ID видео и личные данные не логируются.

## 2. Пользовательский интерфейс на TV (DPAD)

### Меню карточки канала (долгое нажатие на канал в разделе «Каналы»):
* **Открыть канал**: стандартный переход к содержимому канала.
* **Удалить из группы «%s»**: отображается в 1 клик, если в данный момент раздел отфильтрован по конкретной группе.
* **Группы каналов...**: открывает диалог со списком существующих групп и чекбоксами `[x]` / `[ ]`, кнопкой `+ Создать группу` и переходом в `Управление группами`.
* **Отписаться от канала**: стандартное действие YouTube (не затрагивает группы).

### Меню раздела «Каналы» (долгое нажатие на пункт «Каналы» в боковом меню):
* **Группы каналов**:
  - `Все каналы` (сброс фильтра, отображение всех подписок);
  - Список групп: `Новости (5 каналов)`, `Технологии (3 канала)` и т.д. с радио-переключателем;
  - `+ Создать группу`;
  - `Управление группами` (переименование и удаление).
