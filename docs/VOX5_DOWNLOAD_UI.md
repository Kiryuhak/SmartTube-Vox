# VOX 5 — Пользовательский интерфейс скачивания и MediaStore

Состояние: **реализовано и протестировано на эмуляторе Android 14 (API 34)**. База: `origin/main` после PR #43. Дата: 30.09.2026.

## Обзор функциональности

В рамках Patch #6 реализована интеграция скачивания видео с переводом Яндекс VOT непосредственно в пользовательский интерфейс SmartTube для Android TV:

1. **Пункт меню плеера («Скачать с переводом»)**:
   - Добавлен в контекстное меню воспроизведения (`VideoMenuPresenter`) как для авторизованных, так и для неавторизованных пользователей.
   - Динамически определяет статус текущего видео (новое / уже скачано / в процессе скачивания).
   - Защита от попыток скачивания прямых трансляций (Live Streams) с понятным сообщением пользователю.

2. **Диалоговые сценарии для Android TV (`VoxDownloadDialogHelper`)**:
   - **Диалог параметров загрузки**: выбор качества видео (Авто / 1080p / 720p / 360p) и режима перевода (Стандартный / Живые голоса Lively).
   - **Диалог управления существующей загрузкой**: при повторном нажатии на уже скачанном видео предлагает действия:
     - «Открыть / Смотреть локально» — запуск воспроизведения локального MKV-файла.
     - «Скачать заново» — перезапуск процесса загрузки с заменой.
     - «Удалить локальный файл» — удаление из MediaStore и локального репозитория.
     - «Закрыть».
   - **Диалог прогресса загрузки**: отображение этапов в реальном времени с процентами:
     - `ПОДГОТОВКА` (разрешение потоков и заказ перевода)
     - `СКАЧИВАНИЕ_ВИДЕО`
     - `СКАЧИВАНИЕ_АУДИО`
     - `СКАЧИВАНИЕ_ПЕРЕВОДА`
     - `МУКСИРОВАНИЕ`
     - `ПУБЛИКАЦИЯ`
     - `ГОТОВО`
   - Возможность безопасной отмены загрузки на любом этапе с автоматической очисткой временных файлов.

3. **Публикация в системный MediaStore (`VoxMediaStorePublisher`)**:
   - Автоматическая безопасная нормализация имени файла (очистка недопустимых символов `\ / : * ? " < > |`, обрезка до 120 символов, обработка зарезервированных имён Windows `CON`, `PRN`, `AUX`, `NUL` и др.).
   - Сохранение в Scoped Storage директорию `Movies/SmartTube VOX/`.
   - Использование флага `IS_PENDING = 1` во время потоковой записи и перевод в `IS_PENDING = 0` по завершении.
   - Потоковое копирование без создания избыточных копий в памяти.
   - Очистка промежуточных `.part` файлов и временного `output.mkv` после успешной публикации в MediaStore для экономии дискового пространства ТВ-устройств.
   - Поддержка проверки доступности файла по `content://` URI и корректное удаление через `ContentResolver`.

4. **Локальное воспроизведение (`VoxLocalPlayerHelper`)**:
   - Интеграция с `VideoLoaderController` и `TrackSelectorUtil`.
   - Локальный URI передаётся напрямую в ExoPlayer с отключением сетевых запросов к YouTube и Яндекс VOT (`isLocalOfflineMux = true`).
   - Сохранение возможности переключения аудиодорожек между оригиналом и русской дорожкой перевода.

5. **Локализация и изоляция**:
   - Полная поддержка русской и английской локализаций интерфейса и сообщений об ошибках.
   - Изоляция VOT-специфичных строк во флаворе `stvot` с безопасными плейсхолдерами для `ststable`.
   - Отсутствие опасных runtime-разрешений (`MANAGE_EXTERNAL_STORAGE` не требуется).
