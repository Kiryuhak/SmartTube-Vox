# SmartTube VOX — Регламент и стандарт релизов (Release Policy)

Настоящий документ устанавливает строгие правила подготовки, верификации и публикации всех официальных релизов **SmartTube VOX**.

---

## 1. Release Gate и авторизация публикации

1. **Запрет автономного релиза**: ни один AI-ассистент (Antigravity, Codex и др.) не имеет права самостоятельно создавать релизный тег, генерировать финальный GitHub Release или публиковать релизные артефакты.
2. **Явная команда пользователя**: релиз разрешён **исключительно** после прямой команды пользователя со словом **«Выпускаем»**.
3. **Состояние до команды**:
   - `RELEASE_CREATED = NO`
   - `TAG_CREATED = NO`
   - Все промежуточные сборки и патчи сохраняют суффикс `-dev` (например, `32.56-vox.8-dev`).

---

## 2. Именование и версии

- **Release Title**: краткий и единообразный — `SmartTube VOX <N>` (например, `SmartTube VOX 8`).
- **Git Tag**: аннотированный тег в формате `vv<versionName>` (например, `v32.56-vox.8`).
- **versionName**: канонический формат `32.56-vox.<N>`.
- **versionCode**: сквозной целочисленный код (например, `2446009`).
- **Язык публикаций**: все публичные заметки к релизу, описания Pull Request и руководства пользователя оформляются на **русском языке**.

---

## 3. Требования к артефактам и подписи

1. **Только подписанные Release APK**:
   - Запрещено прикреплять отладочные (`debug`) APK к GitHub Release.
   - Сборка выполняется только задачей `assembleStvotRelease`.
2. **Верификация цифровой подписи (APK Signer)**:
   - Перед публикацией каждый APK должен быть проверен через `apksigner verify --print-certs`.
   - Сертификат подписи обязан строго совпадать с эталонным SHA-256:
     ```text
     e07a27097e3ed7b74b3aceb457348e84474930a050e4f2e21d4a6465bd383a2d
     ```
   - **Если отпечаток не совпадает — RELEASE BLOCKED**.
3. **Контрольные суммы (SHA-256)**:
   - Для всех релизных файлов вычисляются контрольные суммы SHA-256.
   - Файл `SHA256SUMS.txt` формируется и прикрепляется к релизу.
   - После загрузки ассетов на GitHub выполняется повторная сверка хэшей загруженных файлов.
4. **Комплект артефактов**:
   - `SmartTube_vot_<version>_armeabi-v7a.apk`
   - `SmartTube_vot_<version>_arm64-v8a.apk`
   - `SmartTube_vot_<version>_universal.apk`
   - `SmartTube_vot_<version>_x86.apk`
   - `SmartTube-VOX-<version>.wgt` (пакет для Samsung Tizen OS)
   - `SHA256SUMS.txt`

---

## 4. Политика безопасности и неразглашения секретов

Строго запрещено коммитить, загружать в артефакты релиза или логировать следующие данные:
- Приватные ключи и файлы хранилищ (`*.jks`, `*.keystore`, `keystore.properties`);
- Переменные окружения и файлы `.env`;
- Секреты Cloudflare Workers (API tokens, Admin Secrets, D1 credentials);
- Приватные сертификаты и профили подписи Tizen Studio (`*.p12`, `author.p12`, `distributor.p12`);
- Отладочные журналы и дампы памяти с пользовательскими токенами, cookies или учетными записями.

---

## 5. Структура Release Notes (Шаблон VOX)

Описание релиза строится строго по стандарту VOX 7: без длинных вводных и маркетинговых текстов, структурированными смысловыми блоками.

1. **Краткий заголовок**: Название релиза, версия, versionCode, тег.
2. **Блоки ключевых функций**:
   ```markdown
   - **Название крупной функции**:
     - конкретное изменение или улучшение;
     - конкретное изменение или улучшение.
   ```
3. **Секция Samsung Tizen TV**: честный статус (Preview / Experimental) с указанием фактических ограничений.
4. **Таблица контрольных сумм SHA-256**: блок кода `text` с контрольными суммами всех файлов.
5. **Отпечаток сертификата подписи**: блок с SHA-256 сертификата APK.
