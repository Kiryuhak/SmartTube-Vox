# SmartTube VOX for Samsung Tizen OS

Платформенный слой **SmartTube VOX** для телевизоров Samsung под управлением Tizen OS.

---

## 1. Концепция и архитектура

SmartTube VOX является **единым продуктом**, разрабатываемым в одном репозитории:

```
SmartTube VOX
├── Android TV / Google TV (Java/Kotlin, APK)
└── Samsung Tizen TV (JavaScript/HTML5, WGT)
```

- **Общий бэкенд и контракты**: Единый OAuth-брокер Яндекс ID, прокси-серверы, классификация ошибок (`VotErrorCategory`) и единая модель возможностей устройств (`vox-device-profile-v1`).
- **Архитектурный подход**: Веб-приложение Tizen / Cobalt UI инъекция + аудиоконтроллер перевода (`TizenTranslatedAudioController`) + навигация с пульта ДУ.
- **Чистая разработка (Clean-room)**: Весь код написан независимо без копирования закрытых или GPL-исходников (проекты TizenTube, TizenBrew использовались исключительно как архитектурно-концептуальные ориентиры).

---

## 2. Команды разработки

В каталоге `tizen/`:

```bash
# Запуск тестов платформы Tizen (возможности, кодеки, DPAD, диагностика, синхронизация)
npm test

# Сборка веб-бандла
npm run build

# Запуск локального Dev Preview с поддержкой клавиатурного пульта
npm run dev

# Сборка пакета WGT (при наличии установленного Samsung Tizen CLI)
npm run package:wgt
```

### Управление в Desktop Preview (`npm run dev`):
- `Стрелки` (Вверх/Вниз/Влево/Вправо) — перемещение фокуса DPAD.
- `Enter` — выбор / активация кнопки.
- `Escape` / `Back` — возврат / закрытие диалога.

---

## 3. Модель возможностей и кодеков (Tizen)

- **Tri-State Capability**: `SUPPORTED`, `UNSUPPORTED`, `UNKNOWN`.
- **Политики выбора кодеков**: `AUTO`, `MAX_QUALITY`, `MAX_COMPATIBILITY`, `CUSTOM`.
- **Синхронизация звука**: Концептуальный порог рассинхрона видео и аудио перевода — 150 мс с автоматической подстройкой позиции.
- **Статус на физическом ТВ**: Физическое тестирование звука на реальном телевизоре Samsung Tizen в рамках текущего этапа — `NOT_TESTED` (реализуется на этапе аппаратной приёмки).
